# singlemotor_steer_using_microros
This code runs on an ESP32 to steer a single rover wheel to whatever angle you command from ROS 2. It listens for target angles on /steer_motor/target_angle and drives the motor clockwise for negative numbers or counter-clockwise for positive numbers. As the wheel turns, the ESP32 counts encoder clicks to stop the motor as soon as it reaches the desired position. At the same time, it constantly reports the wheel's live angle back to your computer at 50 times per second on /steer_motor/current_angle. Everything runs without blocking loops, so control commands and angle updates stay smooth and reliable.
